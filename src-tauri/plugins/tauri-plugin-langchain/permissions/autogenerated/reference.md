## Default Permission

Default permissions for the langchain plugin

#### This default permission set includes the following:

- `allow-spawn-langchain-service`
- `allow-shutdown-langchain-service`
- `allow-health-check`
- `allow-ingest-document`
- `allow-query-rag`
- `allow-get-service-info`
